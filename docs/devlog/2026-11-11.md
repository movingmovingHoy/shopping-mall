## 공부한 것

### 인터셉터는 어디서 실행되나
- 요청 → 필터 → DispatcherServlet → **인터셉터 `preHandle`** → 컨트롤러
- `preHandle`이 `true`를 반환하면 컨트롤러로 진행, 예외를 던지면 컨트롤러에 도달하지 않는다.
- 인터셉터에서 던진 `BusinessException`도 DispatcherServlet이 `@RestControllerAdvice`로 넘겨 준다. 그래서 응답을 직접 쓰지 않아도 다른 에러와 같은 JSON 형식으로 401이 나간다.
- 검사만 하면 되므로 `getSession(false)`. `true`로 하면 로그인 안 한 사람에게도 세션이 생긴다.

### "막을 경로 나열" 대신 "전체를 막고 열 경로만 제외"
- 로그인 필요한 URL을 하나하나 등록하면, 새 API를 만들 때 깜빡하면 **그대로 열린다.**
- `/api/**` 전체를 막고 열어 줄 곳만 제외하면, 깜빡해도 기본값이 '막힘'이라 안전하다.
- `/api/members`를 제외해도 `/api/members/me`는 다른 경로라 막힌다. 패턴은 정확히 일치해야 한다.
- `/api/products/**`를 제외해도 `/api/admin/products`는 막힌다 → 테스트로 확인했다.

### `@Login` 애노테이션과 ArgumentResolver
- 애노테이션 자체는 **표시**일 뿐이다. 실제로 값을 넣는 건 `HandlerMethodArgumentResolver`다.
  - `supportsParameter()`: 이 파라미터를 내가 처리하나? → `@Login`이 붙어 있고 타입이 `Long`이면 처리
  - `resolveArgument()`: 넣을 값을 만든다 → 세션에서 `LOGIN_MEMBER_ID`를 꺼낸다
- `@Target(PARAMETER)`: 파라미터에만 붙일 수 있다.
- `@Retention(RUNTIME)`: 실행 중에도 남아 있어야 리졸버가 확인할 수 있다. 기본값 `CLASS`는 실행할 때 사라진다.
- 덕분에 컨트롤러는 `HttpSession`을 몰라도 된다. `me(@Login Long memberId)`만 쓰면 된다.

### 왜 `Member`가 아니라 id(`Long`)만 넘기나
- 세션에는 id만 있다. `Member`를 넘기려면 리졸버가 **매 요청마다 DB를 조회**해야 한다.
- 장바구니·주문은 대부분 id만 있으면 충분하다. 회원 정보가 필요한 곳만 서비스에서 조회한다.

### 인터셉터와 리졸버의 역할 나누기
- 인터셉터: "로그인 했나?" 검사 / 리졸버: 세션에서 id를 "꺼내기"만
- 리졸버는 인터셉터가 먼저 검사했다고 보고 세션이 있다고 가정한다. 인터셉터 제외 경로에 `@Login`을 쓰면 세션이 없어서 `NullPointerException`이 난다 → 그런 곳에는 쓰지 않는다.
- 지금은 세션을 만드는 곳이 `LoginSessionManager.login()` 하나뿐이라 "세션 있음 = 로그인함"이다. 비회원 장바구니처럼 로그인 없이 세션이 생기는 기능이 생기면 `loginMemberId`가 있는지도 검사해야 한다.

### `MEMBER_NOT_FOUND` (404)
- 세션에 id는 있는데 DB에 회원이 없는 경우(로그인 중에 회원이 삭제됨 등). 인터셉터를 통과했다고 회원이 반드시 있는 건 아니다.
- `findById(...).orElseThrow(...)`로 `Optional`이 비면 바로 예외.

### 테스트
- `@WebMvcTest`는 `WebMvcConfigurer`(`WebMvcConfig`)도 같이 띄운다. 그래서 테스트에서도 실제 경로 규칙, 인터셉터, 리졸버가 그대로 동작한다.
- 인터셉터 테스트는 진짜 컨트롤러 대신 **테스트 전용 컨트롤러**를 같은 URL로 만들었다. `controllers = TestController.class`라 진짜 컨트롤러는 안 떠서 URL이 겹쳐도 충돌하지 않는다.
- 리졸버 단위 테스트: `supportsParameter`는 `@Login Long` / `Long`(애노테이션 없음) / `@Login String` 세 경우로 확인했다.
