## 공부한 것

### `@Login`은 세션에서 회원 id를 꺼내 넣어 준다
- 클라이언트는 회원 id를 보내지 않는다. `LoginMemberArgumentResolver`가 세션의 `loginMemberId`를 꺼내 파라미터에 넣는다.
- 요청 본문으로 `memberId`를 받으면 남의 id를 보내 남의 장바구니를 조작할 수 있다. 세션 값은 서버가 로그인 때 넣은 것이라 바꿀 수 없다.

### 소유자 확인은 조회 SQL 조건으로
- `WHERE id = #{id} AND member_id = #{memberId}`로 조회하면 남의 항목은 "없는 것"이 된다. 서비스에서 `if (소유자 != 나)`를 따로 쓰지 않아도 된다.
- 남의 항목과 없는 항목을 **둘 다 404**로 응답한다. 403으로 구분하면 "그 id가 존재한다"는 정보가 샌다.
- `deleteById`는 id만 보고 지운다. 소유자 확인 조회를 먼저 하지 않으면 남의 항목도 지워진다.

### `@RequestBody` vs `@ModelAttribute`
| | `@RequestBody` | `@ModelAttribute` |
|---|---|---|
| 데이터 | JSON 본문 | 쿼리 파라미터, 폼 |
| 담당 | Jackson | `WebDataBinder` |
| 값 넣는 방식 | 필드에 직접 (리플렉션) | **setter 호출** |
| setter | 불필요 | **필요** |
- 그래서 쿼리 파라미터로 받는 `ProductSearchRequest`, `CartSearchRequest`만 `@Setter`가 있다. (setter가 없으면 값이 조용히 무시되어 기본값이 남는다)
- 컨트롤러 테스트에서 `ArgumentCaptor`로 `page=2&size=5`가 서비스까지 전달되는지 확인한다.

### `WebDataBinder`와 `@RestControllerAdvice`는 다르다
- `WebDataBinder`: 컨트롤러 호출 **전**에 요청 값을 객체에 넣고 변환·검증한다. 실패하면 예외를 **던진다** (`BindException`).
- `@RestControllerAdvice`: 던져진 예외를 **받아서** 공통 JSON(400 등)으로 바꾼다.
- 예외를 만드는 곳은 여럿이다: `WebDataBinder`, `@RequestBody` 처리, 서비스(`BusinessException`), 타입 변환 실패.

### `@Transactional`은 락을 거는 것이 아니다
- 하는 일: 원자성(롤백), 격리 수준에 따른 읽기 일관성. 일반 `SELECT`는 락을 걸지 않는다.
- 다른 요청(스레드)이 `add()`에 동시에 들어오는 것을 막지 않는다. 각 요청은 자기 트랜잭션과 커넥션을 쓴다.
- 담기에서 생길 수 있는 문제
  1. 처음 담을 때 동시 요청 2개: 둘 다 "없음"으로 조회 → 한쪽 INSERT가 유니크 제약에 걸려 500
  2. 이미 담긴 상품에 동시 요청 2개: 둘 다 같은 수량을 읽고 자바에서 더해 UPDATE → **수량이 조용히 틀어짐** (갱신 손실). 에러도 나지 않는다.
- 해결책(나중에): `SET quantity = quantity + ?`(원자적 SQL), `INSERT ... ON DUPLICATE KEY UPDATE`, `SELECT ... FOR UPDATE`

### 조회 전용 객체와 조인
- 장바구니 한 줄에 상품이 1:1이라 `resultMap` 없이 `resultType` + 컬럼 별칭(`p.name AS product_name`)으로 매핑한다.
- 도메인 `CartItem`에 상품 정보를 넣지 않고 조회용 `CartItemDetail`을 따로 둔다.
- `price * quantity`는 `int`끼리 곱하면 21억을 넘을 때 틀린 값이 되므로 `long`으로 바꿔서 곱한다. (SQL은 `CAST(... AS SIGNED)`)
- `SUM`은 행이 없으면 NULL이라 `COALESCE(..., 0)`.

### HTTP 상태 코드
- 담기 201(만들었음), 조회·수량 변경 200, 삭제 204(돌려줄 본문 없음)
- 판매중지 상품 담기는 409: 상품은 있지만 현재 상태가 허용하지 않음
