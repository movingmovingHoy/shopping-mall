## 공부한 것
- **정적 팩토리 메서드 `of`**: `new` 대신 객체를 만드는 static 메서드다. `ErrorResponse.of(code)` 하나로 이름·메시지 꺼내기와 빈 errors 넣기를 한 번에 처리한다. 생성자를 private으로 막으면 `errors`에 null이 들어가는 실수를 막을 수 있다.
- **`@Email`**: `@NotBlank`처럼 Bean Validation이 기본으로 제공한다. 값에 `@`가 들어간 이메일 형식이어야 통과하고, `"not-email"`처럼 `@`가 없으면 검증에 실패해 400 응답이 나간다.
- **MockMvc 테스트**: 톰캣 없이 가짜 HTTP 요청을 보내 응답을 검증한다. `perform(get(...))`로 요청하고, `andExpect(status()...)`로 상태 코드를, `jsonPath("$.code")`로 JSON 값을 확인한다. `@WebMvcTest`는 웹 계층만 띄워서 DB 없이 빠르게 돈다.
- **RuntimeException을 상속하는 이유**: 메서드마다 `throws`를 선언하지 않아도 되고, `@Transactional`은 기본적으로 RuntimeException일 때만 롤백한다.
